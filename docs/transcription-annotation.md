# 人声转录标注规范

## 数据准入

- 每段 15 至 30 秒，必须记录来源、授权范围、是否允许公开再分发、标注者和标注日期。
- Git 只接收明确允许公开再分发的音频与标注。仅获研究或个人使用授权的材料保留在本机，manifest 不记录可识别个人的绝对路径。
- 片段按歌曲和歌手整体划分为 `tuning` 与 `holdout`；同一歌曲的相邻片段不得跨集合。
- 目标集合为 10 至 20 段，覆盖长音、重复同音、颤音、滑音、快音、弱音、换气、不同音域和分离残留。合唱及重叠主唱单独标为超出本轮保证范围。

## 音符口径

- 起音标在稳定可感知音高开始处。无明确音高的送气、爆破和齿音不单独记音符。
- 止音标在有音高发声结束处；尾部纯气声或混响不延长音符。
- 同音高重复演唱在可听见重新起音、短暂清辅音或换气时拆分。连续颤音不按周期拆音。
- 滑音以主要目标音为音符；可辨识且具有独立时值的装饰音单独标注。不确定时保留音符并标记不确定区间，不静默删除。
- 音高可记录整数 MIDI 和可选 cents 偏移。参考音高以该音符稳定段的感知中心为准，不用颤音极值替代中心。

## 复核与记录

- 每段至少完成一次独立复核；有争议的起止边界记录允许范围和原因。
- manifest 的 `tags` 标明场景；标注 JSON 的 `confidence` 表示参考标注确定性，不表示模型置信度。
- 人工修谱评测同时记录耗时和操作数，操作分类为补音、删音、移调、拆分、合并、起音调整和止音调整。
- 发布报告必须列出缺失数据、失败片段和超出支持范围的样本，不得只选择成功片段。
