### 验收标准

- 数字、八度点、附点、横线和延音符使用统一的音乐排版坐标系统，不依赖远程字体。
- 渲染结果在桌面和移动端不溢出、不重叠，播放高亮不会改变布局。
- 每个谱面音符仍能通过稳定 ID 进行选中、编辑和播放定位。
- 简谱显示升级不改变演唱版音符、谱面版音符及 MIDI/MusicXML 导出结果。
- 有浏览器截图和交互验证；第三方依赖的许可证已完成记录。

### 回退方案

保留现有 HTML 简谱渲染器和 `ScoreNote` 数据模型。组件验证失败时，不接入候选依赖，改为在项目内实现 SVG 渲染器，并复用同一套音符 ID、时间轴和播放高亮接口。
